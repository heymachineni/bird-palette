# About Bird Palette

**Bird Palette** (birdpalette) is a free web app that turns **bird plumage** into searchable **color palettes**.

## The idea

Birds already solved color design. Each species carries a real **color combination** — contrast, balance, and character — pulled from nature, not from a palette generator.

Bird Palette collects those combinations so you can:

- Browse **colors of birds** across 10,000+ species
- Search by name, taxonomy, or exact hex
- Copy swatches for art, UI, illustration, and research

## Features

| Feature | Description |
|---------|-------------|
| Plumage palettes | Proportional color bars with hex codes and share % |
| Search | Text, color families, exact `#RRGGBB` |
| Bird detail | Photo, Wikipedia summary, palette study, related birds |
| Photo sampling | Hover/tap the image to read pixel colors |
| Sounds | Field recordings when available (Xeno-canto) |
| Research birds | Curated entries (e.g. juvenile herons from contributor photos) |

## Audience

- Designers seeking **nature color palette** inspiration
- Birders and **ornithology** enthusiasts
- Educators explaining **biodiversity** and plumage
- Anyone searching **bird color combinations**

## Not a generic palette tool

Colors are extracted from **real bird photographs** at build time. The catalog reflects plumage as it appears in sourced images — including juveniles, hybrids, and regional variation when documented.
